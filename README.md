# 🎙️ Podcast Manager API

Uma Web API desenvolvida com **Node.js e TypeScript**, construída sem a utilização de frameworks, com o objetivo de praticar os fundamentos do desenvolvimento de APIs utilizando os recursos nativos do ecossistema Node.js.

O projeto tem como contexto o gerenciamento e consulta de informações relacionadas a podcasts e episódios.

## 🚀 Sobre o projeto

O **Podcast Manager API** é um projeto desenvolvido para colocar em prática conceitos fundamentais do desenvolvimento backend, utilizando Node.js diretamente, sem frameworks como Express, Fastify ou NestJS.

A aplicação utiliza **TypeScript** para tipagem e organização do código, permitindo trabalhar com os principais conceitos envolvidos na construção de uma Web API, como:

* Servidor HTTP;
* Requisições e respostas HTTP;
* Rotas;
* Métodos HTTP;
* Manipulação de dados;
* Tipagem com TypeScript;
* Organização de uma aplicação backend;
* Variáveis de ambiente;
* Execução e compilação de código TypeScript.

## 🛠️ Tecnologias utilizadas

* **Node.js**
* **TypeScript**
* **tsup** — bundler utilizado para gerar a versão de distribuição da aplicação
* **tsx** — execução do TypeScript durante o desenvolvimento
* **HTTP nativo do Node.js**

A pasta `src` concentra o código-fonte da aplicação.

O arquivo `.env` é utilizado para armazenar configurações do ambiente de execução, enquanto o `tsconfig.json` contém as configurações do TypeScript.

## 🔌 API

A aplicação disponibiliza endpoints HTTP para trabalhar com os dados relacionados aos podcasts.

Os endpoints são organizados de acordo com os recursos disponíveis na aplicação e utilizam os métodos HTTP correspondentes a cada operação.

## 🧠 Conceitos praticados

Este projeto foi desenvolvido principalmente para praticar os fundamentos de desenvolvimento backend com Node.js.

Entre os conceitos trabalhados estão:

* Desenvolvimento de Web APIs;
* Node.js sem framework;
* TypeScript;
* HTTP;
* Rotas;
* Métodos HTTP;
* Requisições e respostas;
* Manipulação de dados;
* Variáveis de ambiente;
* Estruturação de projetos backend;
* Compilação de aplicações TypeScript;
* Desenvolvimento em ambiente local.

## 🎯 Objetivo do projeto

O principal objetivo deste projeto é compreender melhor como uma Web API funciona internamente, utilizando os recursos disponíveis no próprio Node.js antes de recorrer a frameworks de desenvolvimento.

A abordagem permite entender conceitos fundamentais que posteriormente podem ser aplicados em projetos utilizando frameworks e bibliotecas mais completas.
